คณิตศาสตร์ ม.4

ความหมายของเซตและสมาชิก

เซต คือ กลุ่มของสิ่งต่าง ๆ ที่ระบุได้อย่างชัดเจนว่าสิ่งใดเป็นสมาชิก เขียนสมาชิกภายในวงเล็บปีกกา { } และใช้ตัวอักษรภาษาอังกฤษตัวใหญ่แทนชื่อเซต

การเขียนและอ่านสัญลักษณ์

ถ้า A = {1, 2, 3} แล้ว 2 ∈ A อ่านว่า 2 เป็นสมาชิกของ A ส่วน 5 ∉ A อ่านว่า 5 ไม่เป็นสมาชิกของ A

เซตเดียวกันเขียนสมาชิกซ้ำได้เพียงครั้งเดียว เช่น {1, 1, 2} คือเซตเดียวกับ {1, 2} และลำดับสมาชิกไม่มีผล

การเขียนแสดงเซต

เขียนเซตได้ทั้งแบบแจกแจงสมาชิก และแบบบอกเงื่อนไขของสมาชิก อ่านเครื่องหมาย “|” ว่า “โดยที่”

ตัวอย่างแบบบอกเงื่อนไข

S = {x ∈ ℤ | x² = 4} หมายถึงเซตของจำนวนเต็ม x ที่ทำให้ x² เท่ากับ 4 ดังนั้น S = {−2, 2}

เซตจำกัด เซตอนันต์ และเซตพิเศษ

เซตจำกัดมีจำนวนสมาชิกจำกัด เช่น {2, 4, 6} ส่วนเซตอนันต์มีสมาชิกไม่สิ้นสุด เช่น เซตของจำนวนเต็มบวก

  • เซตว่าง เขียน ∅ หรือ { } เป็นเซตที่ไม่มีสมาชิก และ n(∅) = 0
  • เอกภพสัมพัทธ์ เขียน U คือเซตที่กำหนดขอบเขตของสมาชิกทั้งหมดที่กำลังพิจารณา
  • จำนวนสมาชิก ของเซตจำกัด A เขียน n(A)
ตัวอย่าง

ถ้า U = {1, 2, 3, 4, 5, 6} และ A = {2, 4, 6} จะได้ n(A) = 3

เซตย่อยและเซตเท่ากัน

A ⊆ B หมายถึง สมาชิกทุกตัวของ A เป็นสมาชิกของ B ด้วย ส่วน A ⊂ B ใช้เมื่อ A เป็นเซตย่อยแท้ของ B (และ A ไม่เท่ากับ B) เซตว่างเป็นเซตย่อยของทุกเซต และทุกเซตเป็นเซตย่อยของตัวเอง

A = B เมื่อ A และ B มีสมาชิกเหมือนกันทุกตัว โดยไม่คำนึงถึงลำดับที่เขียน

ตัวอย่าง

ให้ A = {1, 2} และ B = {1, 2, 3} จะได้ A ⊆ B แต่ A ≠ B

การดำเนินการระหว่างเซต

  • ยูเนียน A ∪ B รวมสมาชิกที่อยู่ใน A หรือ B หรือทั้งสองเซต โดยไม่เขียนซ้ำ
  • อินเตอร์เซกชัน A ∩ B เลือกสมาชิกที่อยู่ร่วมกันทั้งใน A และ B
  • ผลต่าง A − B เลือกสมาชิกที่อยู่ใน A แต่ไม่อยู่ใน B โดย A − B = A ∩ B′
  • ส่วนเติมเต็ม A′ เลือกสมาชิกใน U ที่ไม่อยู่ใน A
ลองไล่สมาชิก

ถ้า A = {1, 2, 3} และ B = {3, 4} จะได้ A ∪ B = {1, 2, 3, 4}, A ∩ B = {3} และ A − B = {1, 2}

แผนภาพเวนน์และกฎของเซต

ในแผนภาพเวนน์ สี่เหลี่ยมแทน U และวงกลมแทนเซต พื้นที่วงกลมซ้อนกันคือสมาชิกที่อยู่ร่วมกัน การระบายพื้นที่ช่วยแสดงผลของยูเนียน อินเตอร์เซกชัน และส่วนเติมเต็มได้

  • สลับที่: A ∪ B = B ∪ A และ A ∩ B = B ∩ A
  • เปลี่ยนหมู่: (A ∪ B) ∪ C = A ∪ (B ∪ C) และ (A ∩ B) ∩ C = A ∩ (B ∩ C)
  • แจกแจง: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  • เดอมอร์แกน: (A ∪ B)′ = A′ ∩ B′ และ (A ∩ B)′ = A′ ∪ B′
จำนวนสมาชิกของยูเนียน

เมื่อนับสมาชิก A ∪ B ต้องไม่รวมสมาชิกในส่วนซ้ำสองครั้ง ดังนั้น n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

เช่น n(A) = 8, n(B) = 6 และ n(A ∩ B) = 2 จะได้ n(A ∪ B) = 8 + 6 − 2 = 12

กิจกรรมชวนคิด: จัดกลุ่มสิ่งของ

ลองเลือกสิ่งของหรือข้อมูลใกล้ตัว แล้วกำหนดกลุ่ม 2–3 กลุ่ม เช่น “ของที่เป็นสีแดง” และ “ของที่ทำจากพลาสติก” จากนั้นเขียนสมาชิกของแต่ละเซต วาดแผนภาพเวนน์ และอภิปรายว่าสิ่งใดอยู่ในส่วนซ้อนกัน

ตรวจคำตอบโดยถามว่า: กำหนดสมาชิกชัดเจนหรือไม่? มีสมาชิกใดอยู่ทั้งสองกลุ่ม? สมาชิกใดอยู่ในกลุ่มแรกแต่ไม่อยู่ในกลุ่มที่สอง?

จำไว้: อ่านสัญลักษณ์ให้ถูกก่อน แล้วพิจารณาว่าสมาชิกอยู่ในเซตใด พื้นที่ส่วนใดในแผนภาพเวนน์ตรงกับโจทย์
